# Portfolio de Yassine

Ce dépôt contient un portfolio statique en français présentant le profil de Yassine.

## Aperçu

- Section d'accueil avec navigation collante et menu mobile.
- Présentation, compétences, projets sélectionnés et coordonnées.
- Design moderne avec dégradés, cartes vitrées et boutons animés.

## Utilisation

Ouvrez simplement `index.html` dans votre navigateur préféré.

Pour lancer un serveur local :

```bash
python -m http.server
```

Puis rendez-vous sur <http://localhost:8000>.
